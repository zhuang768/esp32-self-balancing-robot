# ESP32 Dual-Board Self-Balancing Robot

一台以 ESP32 為核心、採雙主板架構的兩輪自平衡機器人。主板 A 負責姿態估測、PID 平衡與馬達控制；主板 B 規劃負責 Wi-Fi 影像串流。

> 專案狀態：開發中。所有程式均已完成編譯檢查，但完整硬體整合、馬達方向、IMU 安裝方向、PID 參數與相機相容性仍在實機驗證。

## 系統架構

### 主板 A：即時平衡控制

- ESP32-32S / NodeMCU-32S 相容開發板
- MPU6050 六軸 IMU
- TB6612FNG 雙馬達驅動器
- 兩顆 TT 減速馬達
- 0.96 吋 I2C OLED
- 選配蜂鳴器
- 200 Hz 控制迴圈
- 互補濾波與 PID 控制
- 跌倒、感測器異常、啟用角度與 PWM 上限保護

### 主板 B：影像串流實驗

- HW-297 ESP32-CAM 類型開發板
- 獨立 Wi-Fi 串流程式
- 目前相機模組為 RHYX M21-45；腳位與 JPEG 格式相容性尚待確認

## 主板 A 腳位規劃

| 功能 | ESP32 GPIO | TB6612FNG / 周邊 |
| --- | ---: | --- |
| I2C SDA | 21 | MPU6050、OLED SDA |
| I2C SCL | 22 | MPU6050、OLED SCL |
| 左馬達 PWM | 16 | PWMA |
| 左馬達方向 | 17、18 | AIN1、AIN2 |
| 右馬達 PWM | 19 | PWMB |
| 右馬達方向 | 23、25 | BIN1、BIN2 |
| 蜂鳴器 | 27 | 選配；預設停用 |

TB6612FNG 的邏輯電源使用 3.3V。VM 是獨立馬達電源，不經 ESP32 排針或麵包板供應馬達電流。所有模組必須共地。

## 安全設計

- 開機後馬達預設停止，不會自動啟用平衡。
- 只有在機器人接近直立時，序列指令 `e` 才能啟用控制。
- `x` 可立即停止馬達。
- 超過跌倒角度或 IMU 讀值異常時自動停止。
- 初期最大 PWM 限制為 120，確認硬體與方向後才逐步調高。
- 蜂鳴器類型尚未確認，因此預設停用。

## 主板 A 序列指令

Arduino Serial Monitor 設為 115200 baud：

| 指令 | 功能 |
| --- | --- |
| `e` | 在安全角度內啟用平衡控制 |
| `x` | 立即停止馬達 |
| `c` | 停止馬達並重新校正 IMU |
| `p` | 顯示狀態、角度與 PID 輸出 |
| `h` | 顯示指令說明 |

## 編譯環境

- Arduino IDE 2.3.10
- ESP32 Arduino Core 3.3.11
- 主板 A：`NodeMCU-32S`
- 主板 B：`AI Thinker ESP32-CAM`，僅用於目前的編譯檢查

需要安裝下列 Arduino 函式庫：

- `MPU6050`
- `PID_v1`
- `Adafruit GFX Library`
- `Adafruit SSD1306`

## 實機驗證前必須確認

1. ESP32 實板絲印與程式腳位一致。
2. MPU6050 安裝軸向與角度正負方向正確。
3. 左右馬達正反轉方向正確。
4. 5V、3.3V、VM 與共同 GND 沒有短路或接反。
5. 輪子架空後先執行 `Motor_Test`，再進行平衡控制。
6. 依實際機構重新調整 PID，不把目前數值視為完成參數。

## 已知限制

- 目前 ESP32 板的上傳序列同步仍在排查，主板 A 新版韌體尚未寫入實機。
- PID 數值、馬達反相設定與 IMU 軸向必須由實機測試決定。
- RHYX M21-45 的 pinout 與影像格式未取得可靠資料，因此相機功能不列為完成項目。
